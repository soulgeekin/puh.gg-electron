# puh4PC

Electron app that turns puh.gg (dashboard) into an electron app

to download go into either "WINDOWS" or "MAC" and download the folder, then (while making sure u have [nodejs](https://nodejs.org)) installed type into either cmd or terminal how ever you call it "npm install" then "npm run build". then enter the "dist" folder and look for either "Puh Setup 1.0.0.exe" or "Puh-1.0.0.dmg" depending on what operating system your using and open it.
